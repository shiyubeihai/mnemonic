# Mnemonic · 记忆宫殿

把要记的东西放进熟悉的房间，按路线走一遍取回来。

在线玩：**https://shiyubeihai.github.io/mnemonic/**

## 内容

| 入口 | 说明 |
|---|---|
| 家 · 发展心理学 | 7 间房 47 处，312 核心要点，四套配色 |

## 怎么玩

1. **摆**：进房间，逐处看要点，写一句画面。
2. **走**：只给位置和画面，先自己说出要点，再看答案。
3. **评**：忘了 / 模糊 / 记住了，进度自动记在本机。
4. **补**：只复习这一轮没记住的。

## 特点

- 单文件 HTML，无外部依赖，双击即开
- 画面提示、三档自评、四套配色
- 备份导出 / 导入（JSON）
- 电脑与手机浏览器都能用

## 本地打开

下载整个仓库，双击 `index.html`。
